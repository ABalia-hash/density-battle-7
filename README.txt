БИТВА ПЛОТНОСТЕЙ — СЕТЕВАЯ ИГРА ДЛЯ 7 КЛАССА

Важное отличие: это НЕ автономный HTML-файл. Для одновременной игры телефонов нужен запущенный Node.js сервер с доступом в интернет.

БЫСТРЫЙ ЗАПУСК НА КОМПЬЮТЕРЕ
1. Установите Node.js 18 или новее.
2. Откройте терминал в этой папке.
3. Выполните: npm install
4. Выполните: npm start
5. На компьютере откройте http://localhost:3000

ЧТОБЫ ИГРАЛИ УЧЕНИКИ СО СВОИХ ТЕЛЕФОНОВ
Разместите проект на Node.js хостинге (например, Render Web Service):
1. Создайте репозиторий GitHub и загрузите содержимое папки.
2. На Render выберите New > Web Service, подключите репозиторий.
3. Build Command: npm install
4. Start Command: npm start
5. После развёртывания откройте публичный https-адрес, нажмите «Создать игру».
6. Скопируйте ссылку с кодом комнаты ученикам (можно отправить в WhatsApp).

На бесплатном тарифе хостинг может засыпать при простое. Комнаты и результаты хранятся только в оперативной памяти: после перезапуска сервера они исчезнут. Для урока держите сервер включённым и не перезапускайте.

ПРАВИЛА
4 команды: красная, синяя, зелёная, жёлтая; до 7 учеников в каждой.
12 вопросов, 3 раунда по 4 вопроса. 30 секунд на вопрос, 2 балла за верный ответ.
Учитель вручную показывает правильный ответ и переключает вопросы; таймер автоматически открывает правильный ответ.
Учитель получает секретный ключ комнаты, сохранённый в браузере. Не сообщайте ключ ученикам.

ВНИМАНИЕ ПО БЕЗОПАСНОСТИ
Это учебная демонстрационная версия, не полноценная защищённая школьная платформа. Не вводите фамилии, телефоны, оценки и другую личную информацию. Для большого публичного использования потребуется постоянное хранение, авторизация учителя и дополнительная защита.
